# Asset Now

เว็บไซต์นำเสนอผลงานออกแบบ ก่อสร้าง และตกแต่งภายใน

ชื่อแบรนด์ที่แสดงบนเว็บไซต์: **Asset Now**  
ชื่อนิติบุคคลและข้อมูลติดต่อ: **บริษัท จีบ แฟคทอรี่ จำกัด**

## Deploy ด้วย GitHub Pages

อัปโหลดเนื้อหาทั้งหมดในโฟลเดอร์นี้ไปยัง root ของ repository ชื่อ `asset-now` แล้วตั้งค่า GitHub Pages ให้เผยแพร่จาก `main` และ `/(root)`.
